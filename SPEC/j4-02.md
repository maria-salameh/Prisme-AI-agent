# Checkpoint J4-02 — La revue de code

Mon bot a ouvert une pull request depuis la branche `bot/amelioration-affichage`. Elle a l'air anodine, mais elle cache trois défauts. Relisez-la et laissez des commentaires de revue sur les lignes fautives, avec une phrase qui dit le problème et la piste. Ne la fusionnez pas. Le premier palier vérifie que la pull request n'est pas fusionnée et que vous avez commenté au moins trois de ses lignes piégées.

Il y a aussi un défaut déjà dans `main`, semé avant vous : une régression dans `public/js/brain.js`. Corrigez-la et ajoutez un test qui est rouge sur la version abîmée et vert sur la vôtre. Le second palier vérifie le correctif et ce test.

Pour le bonus, votre `eslint.config.js` interdit `innerHTML` et les clés secrètes écrites dans le code. Poussez avant le gel.
