# Checkpoint J3-03 — Votre propre serveur

Dans `server/serveur.mjs`, écrivez la route `POST /api/chat`. Elle reçoit `{ "message": "..." }`, répond `200` avec `{ "reply": "..." }` en suivant vos trois règles, et sinon une phrase de repli avec le nom de l'assistant. Vous pouvez réutiliser `public/js/brain.js`. Le premier palier vérifie cette route avec vos règles.

Le second palier vérifie les erreurs et la version. Un message vide, fait d'espaces, ou plus long que la limite de votre variante donne `400`. La route `GET /version.json` renvoie `{ "sha": "..." }` avec le SHA du commit en cours, lu avec `git rev-parse HEAD`.

Pour le bonus, un corps qui n'est pas du JSON donne `400` et non une panne, et toute autre méthode que `POST` sur `/api/chat` donne `405`. Gardez la fonction `demarrer({ port, racine })` : j'importe votre serveur pour le tester. Poussez avant le gel.
