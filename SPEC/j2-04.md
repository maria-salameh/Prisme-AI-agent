# Checkpoint J2-04 — Travailler à deux avec Git (boss)

Créez une branche dont le nom commence par `feat/`, par exemple `feat/version`. Dans `public/js/version.js`, changez la valeur de `VERSION` en « 0.2.0 », faites un commit, poussez la branche et ouvrez une pull request vers `main`. Le premier palier vérifie que la branche et la pull request existent.

Pendant que vous travaillez, mon bot pousse un commit sur `main` qui change la même ligne. Ne fusionnez pas avant que je l'aie annoncé. Ensuite ramenez `main` dans votre branche, résolvez le conflit en gardant « 0.2.0 », poussez, puis fusionnez la pull request. Ne réécrivez jamais l'historique de `main` : pas de `push --force`. Le second palier vérifie que le commit du bot est toujours dans `main`, qu'aucune marque de conflit ne reste, que la pull request est fusionnée, et qu'aucun secret n'a été commité, même supprimé ensuite.

Pour le bonus, votre `git log --graph` montre deux fusions : celle de `main` dans votre branche, puis celle de la pull request. Il n'y a pas de seconde chance sur ce boss. Poussez avant le gel.
