# Checkpoint J2-03 — Une conversation qui survit au rechargement

Sauvegardez l'état dans `localStorage`, sous la clé de votre variante (`VARIANTE.md`), en JSON, après chaque changement. Au chargement de la page, relisez-le et redessinez l'écran. Si je recharge la page, je retrouve ma conversation. C'est le premier palier.

Le second palier vérifie la robustesse. Si la valeur est absente, si ce n'est pas du JSON valide, ou si ce n'est pas un tableau, la page démarre avec un historique vide et aucune erreur dans la console. Un `JSON.parse` sans `try` est le piège habituel.

Pour le bonus, la page sait relire l'ancien format : un simple tableau de textes, comme `["bonjour", "aide"]`. Chaque texte devient un message de l'utilisateur. Poussez avant le gel.
