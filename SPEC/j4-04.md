# Checkpoint J4-04 — L'incident (boss)

Mon bot a poussé sur `main` un commit « perf » qui est parti en production et qui casse votre assistant. Réparez avec `git revert` sur le commit fautif : pas de `git reset`, pas de `push --force`, l'historique doit garder le commit fautif et le commit d'annulation. Le premier palier vérifie le revert, que votre assistant répond de nouveau selon vos règles, que `/version.json` renvoie le SHA du commit réparé, et que vos tests unitaires sont verts.

Écrivez ensuite `POSTMORTEM.md` avec cinq sections : Résumé, Chronologie (avec au moins trois heures, par exemple 14:02), Cause, Résolution, Leçons. Chaque section dit quelque chose, sans chercher de coupable. C'est le second palier.

Pour le bonus, ajoutez après l'incident un commit avec un test de non-régression qui est rouge sur la version fautive. Il n'y a pas de seconde chance sur ce boss. Poussez avant le gel.
