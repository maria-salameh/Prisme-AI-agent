# Checkpoint J2-01 — Un état, et un écran qui en découle

Votre conversation vit maintenant dans un tableau `etat`, dont chaque élément est `{ role, text }`, avec `role` valant « user » ou « bot ». Pour que le correcteur le voie, exposez-le avec `window.etat = etat`. Ensuite l'écran doit toujours être redessiné à partir de ce tableau : si j'ajoute une ligne dans `etat` à la main, elle apparaît au prochain message. Le premier palier vérifie cela.

Le second palier vérifie la sécurité. Un message comme `<img src=x onerror=...>` doit s'afficher comme du texte, tel quel, sans jamais être interprété par le navigateur. Écrivez le texte avec `textContent`, jamais avec `innerHTML`.

Pour le bonus, l'historique garde 20 messages au plus, dans l'état comme à l'écran : le plus ancien part en premier. Poussez avant le gel.
